GUÍA MAESTRA DE TIEMPOS GRAMATICALES

1. PRESENT SIMPLE

Uso: Rutinas, verdades universales y horarios fijos. AFFI. [ Sujeto ] + Verbo (-s/es para He/She/It) + [ Comp. ] NEG. [ Sujeto ] + Don’t / Doesn't + Verbo (Base) + [ Comp. ] INT. Do / Does + [ Sujeto ] + Verbo (Base) + [ Comp. ] ? REGLAS: Terminación -es en verbos terminados en -o, -sh, -ch, -ss, -x. Consonante + y cambia a -ies (study -> studies). Auxiliares Do/Does eliminan la -s del verbo. Uso de adverbios de frecuencia (Always, usually, never).

2. PRESENT CONTINUOUS

Uso: Acciones ahora o planes futuros confirmados. AFFI. [ Sujeto ] + Am / Is / Are + Verbo (-ing) NEG. [ Sujeto ] + Am not / Isn’t / Aren’t + Verbo (-ing) INT. Am / Is / Are + [ Sujeto ] + Verbo (-ing) ? REGLAS: Quitar -e muda antes de añadir -ing (dance -> dancing). Duplicar consonante en verbos C-V-C (run -> running). No usar con verbos de estado (believe, want, love). Indica molestia si se usa con Always.

3. PRESENT PERFECT SIMPLE

Uso: Acciones pasadas que conectan con el presente. AFFI. [ Sujeto ] + Have / Has + Pasado Participio NEG. [ Sujeto ] + Haven’t / Hasn’t + Pasado Participio INT. Have / Has + [ Sujeto ] + Pasado Participio ? REGLAS: Since (punto específico) y For (duración). Already y Just van entre auxiliar y participio. Yet solo al final de negación e interrogación. Has es exclusivo para la 3ª persona (He, She, It).

4. PRESENT PERFECT CONTINUOUS

Uso: Énfasis en la duración de una actividad que sigue. AFFI. [ Sujeto ] + Have / Has been + Verbo (-ing) REGLAS: No usar para acciones muy cortas o instantáneas. Responde a la pregunta How long...?. Preferir forma simple para mencionar cantidad de veces.

5. PAST SIMPLE

Uso: Acciones terminadas en un tiempo exacto del pasado. AFFI. [ Sujeto ] + Verbo Pasado (ed / irregular) NEG. [ Sujeto ] + Didn’t + Verbo (Base) INT. Did + [ Sujeto ] + Verbo (Base) ? REGLAS: Consonante + y cambia a -ied (try -> tried). Auxiliar Did obliga al verbo a volver a forma base. Verbos irregulares cambian solo en afirmativo. Uso con expresiones cerradas (Yesterday, ago).

6. PAST CONTINUOUS

Uso: Acción en progreso interrumpida en el pasado. AFFI. [ Sujeto ] + Was / Were + Verbo (-ing) REGLAS: When + Past Simple / While + Past Continuous. Describe el contexto de una historia. Was (I, He, She, It) / Were (You, We, They).

7. PAST PERFECT SIMPLE

Uso: Acción que ocurrió antes que otra acción pasada. AFFI. [ Sujeto ] + Had + Pasado Participio REGLAS: Equivale al "había" en español. Auxiliar Had para todos los sujetos. Común en estilo indirecto (Reported Speech).

8. PAST PERFECT CONTINUOUS

Uso: Duración de una acción antes de otra acción pasada. AFFI. [ Sujeto ] + Had been + Verbo (-ing) REGLAS: No se usa con verbos de estado (Stative Verbs). Muestra la causa de un efecto en el pasado.

9. FUTURE SIMPLE (WILL)

Uso: Decisiones rápidas, promesas o predicciones. AFFI. [ Sujeto ] + Will + Verbo (Base) NEG. [ Sujeto ] + Won’t + Verbo (Base) INT. Will + [ Sujeto ] + Verbo (Base) ? REGLAS: No se usa para planes ya organizados. Se usa tras verbos de opinión (Think, hope). Shall se usa para ofrecer ayuda (I/We).

10. FUTURE (GOING TO)

Uso: Planes decididos o predicciones con evidencia. AFFI. [ Sujeto ] + Am / Is / Are going to + Verbo (Base) REGLAS: Requiere verbo To Be conjugado. Informalmente se pronuncia como "Gonna".

11. FUTURE CONTINUOUS

Uso: Acción en curso en un momento futuro específico. AFFI. [ Sujeto ] + Will be + Verbo (-ing) REGLAS: Indica que una acción durará un tiempo en el futuro. Pregunta educada sobre planes ajenos.

12. FUTURE PERFECT

Uso: Acción que ya habrá terminado en el futuro. AFFI. [ Sujeto ] + Will have + Pasado Participio REGLAS: Uso frecuente de la expresión By... (Para...). Indica finalización total de una tarea futura.
